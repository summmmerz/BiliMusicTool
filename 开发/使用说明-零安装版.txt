【换成这一版时必看】（只有一句）

────────────────────────────────────────────────────────────────
第一部分　这个程序是干什么的
────────────────────────────────────────────────────────────────

它能帮你做一件事：

    输入一个歌名，它自己去 B 站找到这首歌，把音频下载下来，
    再从视频里把「曲绘」（封面插图）单独存成一张图片，
    然后测出这首歌的速度（每分钟多少拍），
    最后在歌曲最前面加上正好「一拍小节」长度的静音，
    存成一个 44.1kHz / 320kbps 的 MP3 文件。

它还支持你自己电脑里的音乐文件：拖进去，它就帮你做同样的处理。

处理好的文件都在这个文件夹里：

    本文件夹 → output → （歌名）文件夹

每个歌名文件夹里有 4 个文件：

    歌名.mp3                 ← 主要成果，用这个听
    歌名.audio-only.mp3      ← 同上，但没有内嵌封面
    曲绘.png                  ← B 站上传者提供的封面插图
    info.json                ← 这首歌的信息记录（给程序看的，不用管）

第二部分　第一次使用（只需做一次）

这个版本【什么都不需要安装】。
它自带运行环境，解压出来就能直接用。

直接从第三部分开始看就行。

（小提示：请把压缩包【完整解压】到硬盘上再双击启动程序，
  不要在压缩软件的预览窗口里直接双击运行。）

────────────────────────────────────────────────────────────────

第三部分　平时怎么用（每次都要做）
────────────────────────────────────────────────────────────────

    1. 双击「启动程序.bat」

    2. 黑窗口里会出现一个菜单，输入 1 然后按回车：

           [1]  Open the web page   (recommended)
           [2]  Command line mode
           [3]  Check environment
           [4]  Diagnose download
           [0]  Exit

       输入 1，按回车。

    3. 稍等一下，浏览器会自动打开一个页面。
       如果没有自动打开，自己打开浏览器，在地址栏输入：

           http://127.0.0.1:8765/

       然后回车。

    4. 在页面上操作（见第四部分）。

    5. 用完了想关掉程序：直接关掉那个黑色窗口就行。


────────────────────────────────────────────────────────────────
第四部分　页面怎么操作
────────────────────────────────────────────────────────────────

页面顶部有两个标签：

    ● 从 B 站搜索下载        ● 导入本地音乐

────────────────────
方法一：从 B 站搜索下载
────────────────────

    1. 确认当前在「从 B 站搜索下载」这一页。

    2. 在输入框里打字输入歌名，比如：

           千本樱

       然后按回车，或者点右边的「搜索」按钮。

    3. 等一秒左右，下面会出现几张卡片。
       每张卡片是一首搜索结果，上面有封面图、标题、UP主名字、时长。

    4. 【点一下你想要的那张卡片】。
       被选中的卡片边框会变成青绿色。

    5. 往下拉，看到「处理设置」。一般情况下【不用改任何东西】。

    6. 点「开始处理」按钮。

    7. 下面会出现一个进度框，里面会滚动显示处理日志。
       等它显示「已完成」（大约十几秒到一分钟，看网速）。

    8. 完成后会出现：
         · 一个「BPM」的框，显示测出的速度
         · 4 个文件，每个后面有「下载」按钮，歌曲还能在线试听

    【你的文件已经自动存到 output 文件夹了】，
    页面上的「下载」按钮是把文件另存到别处用的，不用也可以。

────────────────────
方法二：处理自己电脑里的音乐
────────────────────

    1. 点页面上方的「导入本地音乐」。

    2. 点中间那个虚线框，会弹出选择文件的窗口；
       或者直接把音乐文件用鼠标拖进那个虚线框。

    3. 文件上传完，「处理设置」里会显示文件名。

    4. 点「开始处理」，后面和上面一样。

────────────────────
如果测出来的 BPM 不对
────────────────────

    「处理设置」里有个「BPM 来源」，默认是「自动检测」。

    如果测出来的速度明显不对，把它改成「手动指定 BPM」，
    然后在旁边的框里填正确的数字（比如 174），再点「开始处理」。

    不知道正确 BPM 是多少也没关系：先按自动的跑一遍，
    成品能听出「开头静音的长短不太对」时再来手动改。


────────────────────────────────────────────────────────────────
第五部分　文件在哪里
────────────────────────────────────────────────────────────────

处理好的文件在这里：

    本文件夹 → output → 歌名文件夹

举例：搜索「千本樱」之后，你会看到

    output\
        【4K超高清】千本桜原版MV feat 初音ミク\
            【4K超高清】千本桜原版MV feat 初音ミク.mp3
            【4K超高清】千本桜原版MV feat 初音ミク.audio-only.mp3
            曲绘.png
            info.json

文件夹名字就是 B 站上那个视频的标题，所以可能比较长、带各种符号。

【想把它拷到手机或 U 盘】：
    打开那个歌名文件夹，只把「.mp3」结尾的那个文件拷走就行。
    （带「.audio-only」的那个也可以，区别只是有没有内嵌封面图。）

第六部分　遇到问题怎么办
────────────────────────────────────────────────────────────────

问题 2：提示「运行环境缺失」（Bundled Python runtime is missing）
    压缩包没解压完整，或者里面的文件被挪动了。
    解决办法：把压缩包重新【完整解压】一次，解压后直接双击
    「启动程序.bat」，不要单独移动或删除任何文件夹。

问题 3：浏览器打开了，但显示「无法访问此网站」
    说明程序还没启动好，或者被防火墙拦住了。
    等十秒刷新一下页面；还不行就关掉黑窗口，重新双击「启动程序.bat」。

问题 4：搜索报错，或者提示 412
    B 站对搜索有防护。解决办法：

    1. 在页面上展开「搜索选项」
    2. 找到「浏览器 Cookie」，选一个你平时用来登录 B 站的浏览器
       （比如 Edge 或 Chrome）
    3. 点旁边的「检查」按钮，看提示
    4. 如果提示「不可用」，把那个浏览器【完全关闭】再点一次「检查」

    另外，等几分钟再试通常就好了。

问题 5：英文歌名搜不到 / 搜出来结果很少
    直接搜这首歌的中文译名，命中率会高很多。

问题 6：提示需要登录 / 这个视频下载失败
    通常是会员视频。按问题 4 的办法配置浏览器 Cookie。

问题 7：处理完了，但某个文件打不开或者很小
    重新跑一次就行。偶尔网络中断会造成文件不完整。

问题 7.5：下载失败，但错误提示是空的

    【先说结论】2026-10-17 之前的旧版有这个毛病，原因已经查明并修好了。
    新版不会再出现。你现在用这个包就不会遇到。

    旧版的病因（不是你的网络问题，也不是没登录）：
    程序里有个小文件叫 yt-dlp.exe，它记着「我的 Python 在哪个文件夹」。
    这个路径是在做程序的那台电脑上写死的（做成 D:\某个文件夹\... 这样），
    包拷到你电脑上以后这个路径不存在了，那个文件一启动就立刻死掉，
    而且死的时候一个字都不往外说——所以界面上就是「音频下载失败：」后面一片空白。

    新版的做法是不再用那个小文件，改成直接让自己的 Python 来干活，
    不管包放在哪个盘、哪个文件夹、文件夹名有没有空格或中文，都不会再坏。

    ── 万一你还是遇到「提示是空的」，按下面做 ──

    1. 双击「启动程序.bat」，在菜单里输入 4 回车
    2. 它会自己尝试下载一次，并把每一步的结果都打印出来
    3. 等它跑完（大约十几秒到一分钟）
    4. 把窗口里的【全部内容】复制下来发回给提供程序的人

    诊断会逐条检查下面这些，哪一条不对会直接写在结果里：
      · 程序实际调用的 yt-dlp 是哪一个、版本是多少
      · 那个 yt-dlp 能不能正常回答（不能的话会写明"这就是退出码1且无输出的原因"）
      · ffmpeg 在不在、能不能用
      · B 站主站 / 接口 / 音频服务器能不能连上、各花了几秒
      · 最后真的下载一次，把完整命令、退出码、输出都打出来

    其他常见原因：
      · 杀毒 / 安全软件拦截了下载 —— 关掉实时防护再试
      · 公司或校园网的代理拦截了 B 站的音频服务器
      · 程序所在的文件夹没有写入权限（比如放在 C 盘根目录或 Program Files）
      · 网络中途断开

    临时办法：换个文件夹重新解压一次（例如放到 D 盘某个文件夹里）再试。
    注意解压出来的路径别太深，也别带奇怪的符号，中文和空格是可以的。

问题 8：想确认电脑环境有没有问题
    双击「启动程序.bat」，在菜单里输入 3 回车，它会自检并打印结果。

第八部分　名词解释
────────────────────────────────────────────────────────────────

Python
    一种免费的编程语言运行环境。这个程序是用它写的，
    所以电脑上必须装它才能跑。装一次就行，以后不用管。

BPM（每分钟拍数）
    歌曲的速度。数字越大歌越快。比如 128 表示每分钟 128 拍。

一拍小节 / 一小节空隙
    音乐里通常 4 拍算一个小节。
    这个程序会在歌曲【最前面】加上正好一个小节长度的静音，
    长度是按测出来的 BPM 算的。比如 128 BPM，一拍是 0.469 秒，
    一小节就是 1.875 秒。所以开头会有 1.875 秒的安静。

曲绘
    歌曲的封面插图。程序会从 B 站视频里把上传者用的封面原图存下来。

kbps（码率）
    音频每秒占多少数据。320kbps 是 MP3 里质量最好的档次。

44.1kHz（采样率）
    CD 音质的标准，每秒记录 44100 次。

Cookie
    浏览器里保存的「已登录」凭据。
    把这个给程序，它就能下载需要登录才能看的视频。
    不配置也能用，只是会员视频下不了。
