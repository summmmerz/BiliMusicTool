这个说明书按顺序做就行，不用跳着看。
遇到不懂的名词，后面「第八部分 名词解释」有白话解释。


────────────────────────────────────────────────────────────────
第一部分　这个程序是干什么的
────────────────────────────────────────────────────────────────

它能帮你做一件事：

    输入一个歌名，它自己去 B 站找到这首歌，把音频下载下来，
    再从视频里把「曲绘」（封面插图）单独存成一张图片，
    然后测出这首歌的速度（每分钟多少拍），
    最后在歌曲最前面加上正好「一拍小节」长度的静音，
    存成一个 44.1kHz / 320kbps 的 MP3 文件。

它还支持你自己电脑里的音乐文件：拖进去，它就帮你做同样的处理。

处理好的文件都在这个文件夹里：

    本文件夹 → output → （歌名）文件夹

每个歌名文件夹里有 4 个文件：

    歌名.mp3                 ← 主要成果，用这个听
    歌名.audio-only.mp3      ← 同上，但没有内嵌封面
    曲绘.png                  ← B 站上传者提供的封面插图
    info.json                ← 这首歌的信息记录（给程序看的，不用管）


────────────────────────────────────────────────────────────────
第二部分　第一次使用（只需做一次）
────────────────────────────────────────────────────────────────

这个程序需要电脑里先装一个叫 Python 的免费软件。
如果电脑里已经装过 Python 3.10 或更新版本，可以跳到第三部分。

第 1 步　找到启动文件
    在本文件夹里找到这个文件：

        启动程序.bat

    （如果看不到「.bat」这几个字母，说明电脑隐藏了文件后缀名，
      那就找名字叫「启动程序」、图标带齿轮的那个。）

第 2 步　双击它
    双击「启动程序.bat」。

    如果出现一个黑色窗口，里面写着
        [ERROR] Python was not found on this computer.
    说明电脑里还没有 Python，按下面第 3 步装好，再重新双击。

第 3 步　安装 Python
    1. 打开浏览器，在地址栏输入下面这个网址，回车：

           https://www.python.org/downloads/

    2. 页面中间有一个黄色大按钮，写着「Download Python 3.x.x」，
       点它，会下载一个安装文件。

    3. 找到刚下载的那个文件，双击运行。

    4. ★★★ 最重要的一步 ★★★
       安装窗口最下面有一个小方框，文字是：

           Add python.exe to PATH

       【必须把它勾上！】这个勾不打，程序就找不到 Python。

    5. 点窗口右下角「Install Now」，等进度走完，点「Close」关闭。

    6. 回到本文件夹，重新双击「启动程序.bat」。

第 4 步　让它自动装组件
    第一次运行，程序会自己下载并安装几个必要的组件。
    黑窗口里会出现这样的字：

        First run: installing required components
        Needs internet access. Usually takes under a minute.

    这一步需要联网，通常不到一分钟。请等它走完，
    【不要关闭这个窗口】。

    走完会显示：
        Components installed successfully.

    如果这里报错，看第六部分的「问题 2」。


────────────────────────────────────────────────────────────────
第三部分　平时怎么用（每次都要做）
────────────────────────────────────────────────────────────────

    1. 双击「启动程序.bat」

    2. 黑窗口里会出现一个菜单，输入 1 然后按回车：

           [1]  Open the web page   (recommended)
           [2]  Command line mode
           [3]  Check environment
           [4]  Diagnose download
           [0]  Exit

       输入 1，按回车。

    3. 稍等一下，浏览器会自动打开一个页面。
       如果没有自动打开，自己打开浏览器，在地址栏输入：

           http://127.0.0.1:8765/

       然后回车。

    4. 在页面上操作（见第四部分）。

    5. 用完了想关掉程序：直接关掉那个黑色窗口就行。


────────────────────────────────────────────────────────────────
第四部分　页面怎么操作
────────────────────────────────────────────────────────────────

页面顶部有两个标签：

    ● 从 B 站搜索下载        ● 导入本地音乐

────────────────────
方法一：从 B 站搜索下载
────────────────────

    1. 确认当前在「从 B 站搜索下载」这一页。

    2. 在输入框里打字输入歌名，比如：

           千本樱

       然后按回车，或者点右边的「搜索」按钮。

    3. 等一秒左右，下面会出现几张卡片。
       每张卡片是一首搜索结果，上面有封面图、标题、UP主名字、时长。

    4. 【点一下你想要的那张卡片】。
       被选中的卡片边框会变成青绿色。

    5. 往下拉，看到「处理设置」。一般情况下【不用改任何东西】。

    6. 点「开始处理」按钮。

    7. 下面会出现一个进度框，里面会滚动显示处理日志。
       等它显示「已完成」（大约十几秒到一分钟，看网速）。

    8. 完成后会出现：
         · 一个「BPM」的框，显示测出的速度
         · 4 个文件，每个后面有「下载」按钮，歌曲还能在线试听

    【你的文件已经自动存到 output 文件夹了】，
    页面上的「下载」按钮是把文件另存到别处用的，不用也可以。

────────────────────
方法二：处理自己电脑里的音乐
────────────────────

    1. 点页面上方的「导入本地音乐」。

    2. 点中间那个虚线框，会弹出选择文件的窗口；
       或者直接把音乐文件用鼠标拖进那个虚线框。

    3. 文件上传完，「处理设置」里会显示文件名。

    4. 点「开始处理」，后面和上面一样。

────────────────────
如果测出来的 BPM 不对
────────────────────

    「处理设置」里有个「BPM 来源」，默认是「自动检测」。

    如果测出来的速度明显不对，把它改成「手动指定 BPM」，
    然后在旁边的框里填正确的数字（比如 174），再点「开始处理」。

    不知道正确 BPM 是多少也没关系：先按自动的跑一遍，
    成品能听出「开头静音的长短不太对」时再来手动改。


────────────────────────────────────────────────────────────────
第五部分　文件在哪里
────────────────────────────────────────────────────────────────

处理好的文件在这里：

    本文件夹 → output → 歌名文件夹

举例：搜索「千本樱」之后，你会看到

    output\
        【4K超高清】千本桜原版MV feat 初音ミク\
            【4K超高清】千本桜原版MV feat 初音ミク.mp3
            【4K超高清】千本桜原版MV feat 初音ミク.audio-only.mp3
            曲绘.png
            info.json

文件夹名字就是 B 站上那个视频的标题，所以可能比较长、带各种符号。

【想把它拷到手机或 U 盘】：
    打开那个歌名文件夹，只把「.mp3」结尾的那个文件拷走就行。
    （带「.audio-only」的那个也可以，区别只是有没有内嵌封面图。）


────────────────────────────────────────────────────────────────
第六部分　遇到问题怎么办
────────────────────────────────────────────────────────────────

问题 1：双击启动程序，黑色窗口一闪就没了
    说明 Python 没装好，或者装的时候没有勾「Add python.exe to PATH」。
    请按第二部分第 3 步重新安装 Python，注意一定要勾那个框。

问题 2：提示组件安装失败（Installing components failed）
    多半是网络问题。按提示手动装一次：

    1. 在「program」文件夹的地址栏里（不是本文件夹）输入 cmd 回车
    2. 在弹出的黑窗口里，复制粘贴下面这一整行，回车：

           python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

    3. 等它走完，再双击「启动程序.bat」

问题 3：浏览器打开了，但显示「无法访问此网站」
    说明程序还没启动好，或者被防火墙拦住了。
    等十秒刷新一下页面；还不行就关掉黑窗口，重新双击「启动程序.bat」。

问题 4：搜索报错，或者提示 412
    B 站对搜索有防护。解决办法：

    1. 在页面上展开「搜索选项」
    2. 找到「浏览器 Cookie」，选一个你平时用来登录 B 站的浏览器
       （比如 Edge 或 Chrome）
    3. 点旁边的「检查」按钮，看提示
    4. 如果提示「不可用」，把那个浏览器【完全关闭】再点一次「检查」

    另外，等几分钟再试通常就好了。

问题 5：英文歌名搜不到 / 搜出来结果很少
    直接搜这首歌的中文译名，命中率会高很多。

问题 6：提示需要登录 / 这个视频下载失败
    通常是会员视频。按问题 4 的办法配置浏览器 Cookie。

问题 7：处理完了，但某个文件打不开或者很小
    重新跑一次就行。偶尔网络中断会造成文件不完整。

问题 7.5：下载失败，但错误提示是空的
    这是最需要处理的情况。请按下面做：

    1. 双击「启动程序.bat」，在菜单里输入 4 回车
    2. 它会自己尝试下载一次，并把每一步的结果都打印出来
    3. 等它跑完（大约十几秒到一分钟）
    4. 把窗口里的【全部内容】复制下来发回给提供程序的人

    常见的几种原因，诊断结果会直接指出：
      · 杀毒 / 安全软件拦截了下载 —— 关掉实时防护再试
      · 公司或校园网的代理拦截了 B 站的音频服务器
      · 程序所在的文件夹没有写入权限（比如放在 C 盘根目录或 Program Files）
      · 网络中途断开

    临时办法：换个文件夹重新解压一次（例如放到 D 盘某个文件夹里）再试。

问题 8：想确认电脑环境有没有问题
    双击「启动程序.bat」，在菜单里输入 3 回车，它会自检并打印结果。

第七部分　文件夹里都有什么（了解一下就行，不用动）
────────────────────────────────────────────────────────────────

    启动程序.bat        ← 只双击这一个。全部功能都从这里进
    使用说明.txt        ← 你正在看的这份
    output\             ← 处理好的文件都在这里

        命令行模式.bat      不想用网页、直接用命令行的版本
        run.bat             命令行入口
        package.py          重新打包用

第八部分　名词解释
────────────────────────────────────────────────────────────────

Python
    一种免费的编程语言运行环境。这个程序是用它写的，
    所以电脑上必须装它才能跑。装一次就行，以后不用管。

BPM（每分钟拍数）
    歌曲的速度。数字越大歌越快。比如 128 表示每分钟 128 拍。

一拍小节 / 一小节空隙
    音乐里通常 4 拍算一个小节。
    这个程序会在歌曲【最前面】加上正好一个小节长度的静音，
    长度是按测出来的 BPM 算的。比如 128 BPM，一拍是 0.469 秒，
    一小节就是 1.875 秒。所以开头会有 1.875 秒的安静。

曲绘
    歌曲的封面插图。程序会从 B 站视频里把上传者用的封面原图存下来。

kbps（码率）
    音频每秒占多少数据。320kbps 是 MP3 里质量最好的档次。

44.1kHz（采样率）
    CD 音质的标准，每秒记录 44100 次。

Cookie
    浏览器里保存的「已登录」凭据。
    把这个给程序，它就能下载需要登录才能看的视频。
    不配置也能用，只是会员视频下不了。
